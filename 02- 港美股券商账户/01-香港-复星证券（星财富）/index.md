## 复星证券开户常见问题

### Q1：复星证券和星财富是什么关系？

星财富是复星证券面向个人投资者使用的 App。用户可以通过星财富 App 申请复星证券账户，并进行港股、美股、美债等资产交易。

### Q2：内地居民可以开复星证券账户吗？

目前复星证券开户需要准备内地身份证、内地银行卡、境外证明，以及香港或其他境外银行卡用于后续出入金。具体要求可能会根据券商审核政策变化，建议开户前先确认最新要求。

### Q3：复星证券开户需要香港银行卡吗？

开户审核阶段不一定只看香港银行卡，但实际入金和出金通常需要香港银行账户或其他境外银行卡。因此，如果你还没有香港银行账户，建议先规划好银行账户和券商账户的开户顺序。

### Q4：复星证券真的港美股终生免佣吗？

通过指定邀请渠道开户，并满足相应入金条件后，可以获得港股、美股、美股期权终生免佣等优惠。不过需要注意，免佣通常不等于完全免费，交易时可能仍会涉及平台费、交易所费用、监管费等第三方费用。

### Q5：复星证券适合作为长桥证券的替代选择吗？

如果你关注港美股低成本交易，同时又因为身份、地区或开户政策原因无法使用长桥证券，复星证券可以作为一个替代选择。尤其是它的港美股终生免佣和美债 0 费用，对低成本投资者有一定吸引力。

### Q6：复星证券美债交易有什么优势？

复星证券的核心优势之一是美债交易 0 费用，包括 0 佣金、0 平台费、0 托管费和 0 代收息手续费。对于有美债资产配置需求的用户，这一点很有优势。
