## 券商交易费用由哪几部分组成？

一笔港股或美股交易的费用，可以拆成两大类：**外部交易所及监管收费**，以及**券商内部费用**。前者基本所有券商都一样，后者才是券商之间费用差异的主要来源。

### 1. 券商内部费用：主要区别在佣金和平台费

券商内部费用才是本文重点比较的部分，主要分为两项：**佣金**和**平台费**。很多券商宣传“0 佣金”或“终生免佣”，通常只免佣金，不代表 0 成本；

### 2. 外部交易所及监管收费：各券商基本一样

外部收费包括印花税、交易征费、交易所交易费、结算费、SEC 规费、FINRA 交易活动费等。这些费用不是券商利润，而是由券商代交易所、监管机构或结算机构收取。所有券商这部分费用都是一样的。

## Webull 微牛为什么可以做到 0 平台费 0 佣金？

很多第一次接触 Webull 微牛证券的用户都会有一个疑问：**券商不收佣金、不收平台费，那它靠什么赚钱？**

其实，“零佣金”并不等于券商没有收入。互联网券商的收入来源已经不再只是股票交易佣金，还包括**融资融券利息、客户现金产生的利息收入、证券借贷收入，以及期权、期货等其他金融产品和交易相关收入**。Webull 的公开财务资料也显示，这些都是其重要收入来源。

因此，Webull 可以把港股和美股股票交易作为低成本的基础服务，用 **0 佣金、0 平台费**吸引更多用户和资产，再通过其他金融服务实现收入。

需要注意的是，**0 佣金、0 平台费并不代表所有交易成本都是 0**。例如港股印花税、交易所及监管机构收取的费用等第三方费用，仍可能需要正常缴纳。

## 比佣金更值得关注的 6 项隐性成本

大部分人对比券商时只看佣金表，但真正长期侵蚀收益的往往是下面这些项目。

- **换汇点差**：港币换美元的点差通常远大于一次交易的平台费。券商内换汇一般优于银行零售汇率，但各家点差不同，是长期成本中被严重低估的一项。
- **出金费用**：例如 uSMART 香港港币出金金额大于 HK$500 免费，但当日快速出金收费 HK$100 / 笔；美元出金还可能被收款银行另收电汇费。频繁出金的成本可能超过交易本身。
- **存仓费 / 托管费**：部分券商对港股或美债持仓收取存仓与托管费用。复星证券美债明确 0 托管费、0 代收息手续费，是本页唯一全免的一家。
- **行情费用**：港股 Lv2、美股 Lv1 / Lv2 实时行情在部分券商需要付费或按月完成交易任务解锁。云锋有鱼注册即享港股 Lv2，uSMART 与致富提供部分免费行情档位。
- **闲置资金机会成本**：账户里躺着的现金如果不进货币基金，一年下来的损失可能远超省下的佣金。复星证券提供余额自动理财，uSMART 与云锋也有货币基金 / 现金管理产品。
- **账户不活跃 / 最低收费**：部分券商对长期不交易的账户或小额账户有额外收费安排，开户前建议确认。

## 「终生免佣」到底免了什么？

本页 7 家券商里有 5 家宣传免佣或终生免佣，但口径完全不同。拆开看，一笔交易的成本其实由三层组成：

1. **券商佣金**：唯一被「免佣」覆盖的部分，也是三层里通常最小的一层。
2. **平台使用费**：券商自己收，但几乎从不包含在免佣活动内。港股每笔 HK$10–15、美股每股 US$0.005–0.009，这才是真正的主要成本。
3. **第三方代收费用**：印花税、交易征费、交易所费、结算费、SEC / FINRA 费，任何券商都免不掉。

此外，「终生免佣」通常附带激活条件。例如复星证券需通过指定渠道开户并完成 HK$20,000 净入金，腾达证券需入金满 HK$10,000，云锋有鱼的免佣是 1 年而非终生。这些条件一旦没满足，费率就会回到标准档。

**唯一例外是 Webull 微牛**：港股与美股同时 0 佣金且 0 平台费，是本页费用结构最干净的一家。代价是它的产品线、账户类型与开户资格另有各自的限制，需要结合自身身份情况判断。

## 券商交易费用常见问题

哪家香港券商交易费用最低？

单看费率，Webull 微牛最低：港股与美股同时 0 佣金且 0 平台费。在收取平台费的券商中，港股最便宜的是云锋有鱼（HK$10 / 笔），美股小额订单最便宜的是致富证券（最低 US$0.99）。但费用只是选券商的一个维度，开户资格、可交易市场与出入金便利度通常影响更大。

港股平台费可以免掉吗？

大多数情况不能。免佣活动几乎都只覆盖券商佣金，不含平台使用费。少数例外是 Webull 港股本身就 0 平台费，以及 uSMART 的月供股票与指定港股 ETF 在活动期内 0 平台费。参加活动前请确认活动条款里是否明确写了「0 平台费」。

「终生免佣」是真的吗？

免的是佣金，不是全部费用。以复星证券为例，需通过指定渠道开户并完成 HK$20,000 净入金后生效，之后港股仍收 HK$15 / 笔平台费，美股仍收 US$0.005 / 股平台费，另有交易所与监管费用。云锋有鱼的免佣期是 1 年而非终生，腾达证券的门槛是入金满 HK$10,000。

港股印花税是多少？换券商能省吗？

截至 2026 年 8 月，港股印花税为成交额 0.1%，买卖双向收取，不足 HK$1 按 HK$1 计。这是政府税项，由券商代收上缴，换任何券商都一样，无法减免。

美股平台费为什么按股收？买低价股会很贵吗？

会。按股计费意味着成本取决于股数而非金额。以 US$6,000 成交额为例，买 100 股 US$60 的股票只需 US$1 左右，买 2,000 股 US$3 的股票在 US$0.009 / 股的券商要付 US$18，相差 18 倍。买美股低价股时，优先选按股单价低（US$0.005 一档）或不按股计费的券商。

小额定投港股，选哪家最省？

每月 HK$3,000 定投一年，普通买盘的券商侧年成本约为：Webull HK$0、云锋有鱼 HK$120、uSMART HK$154.8、复星与腾达 HK$180、致富约 HK$190。更重要的是确认券商是否有专门的月供股票通道，uSMART 与致富的月供活动期内可做到 0 佣金，比普通买盘便宜得多。

美股期权哪家便宜？

本页已核实的数据中，Webull 微牛 US$0.2 / 张（最低 US$1）最低，复星证券为 0 佣金 + US$0.65 / 张平台费，uSMART 香港为 US$0.45 / 张佣金 + US$0.30 / 张平台费，致富证券约 US$0.99 / 张。期权还需支付 OCC、SEC、FINRA 等第三方费用。期权涉及杠杆与时间价值损耗，风险高于股票。

除了交易费用，还有哪些成本要算进去？

至少还有六项：港币换美元的换汇点差、出金手续费（快速出金可能收 HK$100 / 笔）、存仓与托管费、实时行情费用、闲置资金的机会成本，以及账户不活跃可能产生的收费。长期持有者受托管费与换汇点差影响，通常远大于佣金差异。

费用差几十块，值得为此换券商吗？

取决于交易频率。每年交易 10 次以内，各家差异通常在几百港币以内，开户成功率、出入金顺畅度与 App 稳定性更值得优先考虑；每周都交易的用户，一年下来费用差异会放大到几千港币，此时费率结构才真正重要。

为什么不同网站列出的同一家券商费率不一样？

主要有三个原因：一是账户等级不同（如 uSMART 的基本 / Trader / PRO 计划费率各异）；二是新旧收费方案并存，例如致富证券 2026 年 6 月调整过港股收费，部分网站仍展示旧计划（0.0668%、最低 HK$20）；三是活动费率与标准费率混用。判断标准始终是开户时系统显示与官方收费页面。
