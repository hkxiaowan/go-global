<a name="致富证券入金"></a>

## 致富证券入金

投资港股就转入港币，港币支持7×24 小时，无损即时到账。

投资美股则转入美金，或者转入港币后再到券商里面换汇成美金。

由于在香港银行间美金转账不是实时的。可以先通过银行转港币到证券后，再换成美元，效率更高。银行和证券里面都可以随时换汇，通常证券汇率比银行更好。投资美股也建议入金港币后，再在证券里面换成美金。

<a name="1-港币入金：-edda入金，即时到账。"></a>

### 1. 港币入金：Edda入金，即时到账。

首选 Edda入金，即时到账。只需要一次授权绑定，后续就可以直接在证券里面划转资金到证券账户。

![](01-项目库/06-%20go-global/02-%20港美股券商账户/chief/images/15.png)

EDDA 绑定注意事项：

1. 绑定自己对应的港卡银行，如汇丰代号为004，中银为012，众安为387。
2. 货币币种：选港币或者全币种
3. 账户号码：注意是账户号码，不是卡号，账户号码通常在银行APP首页会展示。
4. 银行证件：中银、众安这一类的证件是身份证，汇丰和渣打则是港澳通行证。

![](01-项目库/06-%20go-global/02-%20港美股券商账户/chief/images/16.png)

绑定完成后，就可以直接在致富证券的 APP 里面划转资金到证券账户，需要注意银行的余额是否充足，扣款不成功会产生额外的手续费。

![](01-项目库/06-%20go-global/02-%20港美股券商账户/chief/images/17.png)

<a name="致富证券开户常见-faq"></a>

## 致富证券开户常见 FAQ

内地居民可以开致富证券吗？

可以。致富证券目前仍接受内地居民凭身份证申请，是 522 新政后少数保留该路径的港资券商之一，根据最新的规定，开户时需要确保使用香港的网络才能开户，后续使用不用。

致富证券开户需要香港地址证明吗？

不需要。内地居民申请时重点是身份证与内地银行卡信息，一般无需额外提供境外地址证明。个别用户背景可能触发补充资料要求。

开户一定要香港银行卡吗？

开户环节不需要。香港银行账号步骤可以先跳过，账户开通后再绑定；但入金与出金必须使用本人同名香港银行账户。

注册时提示地区不支持怎么办？

先检查网络出口 IP 是否为香港或海外。致富证券注册环节会校验网络环境，内地 IP 可能无法正常进入流程。

已经自己注册过，再点邀请链接还能拿奖励吗？

不能。渠道关系一般在注册时绑定，事后点击邀请链接无法重新绑定。希望参与渠道活动，应先通过指定链接进入再注册。

可以使用家人的银行账户认证或入金吗？

不可以。身份认证与出入金账户都必须是本人同名账户，非同名账户会导致审核失败或资金退回。

致富证券港股和美股收费是多少？

港股佣金 0.0288% + 每笔 HK$15 平台费；美股 0 佣金，平台费每股 US$0.008，最低 US$0.99，上限为成交额 3%。另需支付交易所、监管及结算等第三方费用。

致富证券适合港股打新吗？

适合作为打新账户之一。现金认购免手续费，融资认购按官方标准收费，且提供打新券类奖励。是否合适取决于你关注的融资倍数、利率与截止时间。

致富证券和富途、老虎、微牛相比如何？

致富证券的核心优势是开户门槛低（内地身份证可开、无需地址证明）与老牌港资背景；互联网券商在 App 体验和功能生态上更现代。如果你的首要问题是「能不能开成」，致富证券的成功率通常更高。

开户资料填错了会影响审核吗？

会。姓名、地址、税务信息、职业信息不一致是最常见的补件与拒批原因，提交前逐项核对。

开户后多久可以交易？

资料齐全的情况下，办公时间内成功开户最快约 30 分钟可交易；实际时间取决于审核队列与资料完整度。
