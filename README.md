# 跨境小万 · 个人出海第一站

从境外银行账户与美股投资开始，逐步了解跨境工具、政策，探索全球机会。

## 01- 境外银行开户
境外银行账户和卡是两个概念，卡只是账户的一个附属工具，在账户开立成功后一般需要单独申请。我们说的银行开户是指开立银行账户。

### 境外银行账户有什么用？

- **境外投资与保险**：用于港美股、美债等投资账户的资金往来，以及香港保险保费缴付、理赔款和到期款接收。
- **海外收入收款**：接收海外工资、自由职业报酬、平台收入及业务款项，连接海外客户与市场。
- **海外消费与订阅**：支付海外购物消费、ChatGPT 等数字服务及软件订阅费用。

### 境外银行卡有哪些选择？

对于大陆居民，常用的境外银行主要是香港、新加坡和美国这三个地区的银行，他们各有优劣势，具体如下：
- **香港：境外账户的入门选择**  
	香港银行优势：开户方便、与内地资金往来便利。
	劣势：香港是 CRS参与地，中国内地税务居民账户信息，会按规定交换回内地税务机关。
	主要的银行：[[内地居民 HSBC香港汇丰银行开户攻略 2026|HSBC]]、恒生、中银香港、渣打、众安银行。
	
    
- **新加坡：兼顾账户地区分散与华语使用体验**
	新加坡银行账户优势：新加坡是一个独立的主权国家，提供不同于香港的司法和金融监管制度，同时又能提供中文服务。
	新加坡银行账户劣势：新加坡是 CRS 参与国。
	支持内地远程开户的新加坡银行有：星展（DBS）、华侨（OCBC）、渣打。这几个银行的开户都有门槛，星展需要存入 100w，渣打需要存入 50w。
	
    
- **美国：无 CRS 交换** 
    美国银行账户优势：美国不参与CRS ，这是大多数国人考虑美国银行账户的重要原因。
    美国银行账户劣势：
    - **维护成本**：有最低存款要求，不满足会被收取账户管理费。
    - **使用成本**： 国内直接汇款到美国银行费用高、被拦截和审查的概率高。
    - **使用便利**：身处内地，处理账户验证、补卡或异常交易等需要考虑客服时差及远程办理限制。
    - **隐形税务问题** ：虽然美国没有加入 CRS，但账户仍然受到美国当地税务法律约束。
    
    目前能够接受内地居民申请的银行不多，主要有：华美银行、国泰银行。
    

## 02- 美股投资

中国内地居民直接投资美股的渠道逐步在收紧，这里介绍的是正规持牌券商。

### 香港券商
香港大部分知名券商，如富途、华盛、长桥等已不再接受内地居民开户申请，目前支持内地居民开户的券商主要有：复星国际证券、致富证券、盈立证券、腾达证券。

香港是 CRS 参与地区，香港券商的账户信息，会按规定交换回内地税务局。

### 新加坡券商
目前支持内地居民开户的新加坡券商只有一家：盈立证券（新加坡），新加坡同样参与 CRS。

### 美国券商：

美国本土券商目前不参与 CRS交换，但开户和出入金等都有很多限制。
目前支持内地居民申请的主要有：IBKR盈透证券、嘉信理财（Charles Schwab）、第一证券（Firstrade）、BBEA 必备证券。


## 03- 跨境投资的合规风险

从近年来的监管政策来看，中国内地对个人跨境证券投资的监管正在进一步收紧，尤其是针对境外券商在境内招揽客户、提供开户和交易服务等行为。

但即便如此，依然挡不住部分投资者参与港美股市场的热情。

原因其实很简单：**资金天然具有逐利性。**

哪里有更好的投资机会，资金就倾向于流向哪里。尤其是过去几年，美股市场涌现出大量优质科技企业，主要指数长期表现突出，对国内投资者形成了很强的吸引力。

虽然跨境投资受到诸多限制，但仍有投资者希望通过各种渠道参与美股市场。

当然，我们在投资港美股的时候，也必须清楚其中的合规风险。

**知道风险之后，经过自己的判断，仍然愿意承担相应的后果；和根本不知道存在这些风险，就稀里糊涂地参与投资，这是完全不同的两回事。**

### 外汇风险

如果你美股投资的资金需要从国内汇出去，这里就会面临第一个风险，就是外汇风险。

按照国家外汇管理局的规定，个人跨境汇款出去的资金，只能用于境外消费和留学等指定目的，不能用于港险、港美股等投资。

在实际操作中，大多数人都是以旅游、消费等名义购汇并将资金汇往香港，随后将这笔资金用于购买香港保险、港股或美股。

按照外汇管理的规定，这个行为本身就是不合规的。现实中为什么很少听到个人被外汇管理处罚呢？

因为外管局监控不到你的资金具体用途。

举个例子，你把一笔 5 万美金的资金通过国内银行汇款到香港银行后，是用于消费还是转入证券账户进行投资，这个信息境外银行通常是不会主动申报给国家外管局的。除非你严重违规，如大额资金转移、地下钱庄对敲等，那就是另外一种情况了。

这就好比交通法规定不能闯红灯，但闯了红灯，并不一定就会被处罚，还需要有相应的监督和执法手段。

**法律上的限制与现实中的执行，是两回事。**



### 税务风险

按照我国《个人所得税法》的规定，中国税收居民不仅需要对境内所得缴税，对境外所得同样负有纳税义务。

其中，投资港美股取得的股票转让收益、股息红利等，通常适用 **20% 的个人所得税税率**。

这里就面临着一个现实问题：

**税务局要想征收你的境外投资所得税，首先得知道你在境外取得了这笔收入。**

过去，由于跨境金融信息不透明，税务机关获取个人境外投资收入信息的渠道相对有限，因此实际征管存在不少困难。

但随着 CRS（共同申报准则）的实施，这种情况正在发生变化。

简单来说，CRS 就是一套国家和地区之间自动交换金融账户涉税信息的机制。

例如，中国内地税收居民在香港开立了银行或证券账户，符合 CRS 申报条件的情况下，香港金融机构会向香港税务局报送相关账户信息，再通过税务机关之间的信息交换机制，将这些信息提供给中国内地税务机关。


**这意味着，即使你的资金一直留在香港，没有汇回内地，内地税务机关也可以获知相关信息。**

事实上，从 2025 年开始，国内已有多地税务机关对未依法申报境外收入的个人开展提醒和查处。

所以，对于参与港美股投资的内地居民来说，税务风险已经不再只是纸面上的法律规定，而是现实中需要认真面对的问题。
