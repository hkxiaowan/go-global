# 跨境小万 · 个人出海第一站

普通人的跨境之路，从境外银行账户与美股投资开始，逐步了解跨境工具、政策，探索全球机会。

## 01- 开一个境外银行账户

### 境外银行账户有什么用？

- **境外投资与保险**：用于港美股、美债等投资账户的资金往来，以及香港保险保费缴付、理赔款和到期款接收。
- **海外收入收款**：接收海外工资、自由职业报酬、平台收入及业务款项，连接海外客户与市场。
- **海外消费与订阅**：支付海外购物消费、ChatGPT 等数字服务及软件订阅费用。

### 境外银行卡有哪些选择？

对于大陆居民，常用的主要是香港、新加坡和美国这三个地区的银行。他们各有优劣势，具体如下：
- **香港：境外账户的入门选择**  
	- **优势**：开户方便、与内地资金往来便利。
	- **劣势**：香港是 CRS参与地，中国内地税务居民账户信息，会按规定交换回内地税务机关。
	- **支持内地用户申请的香港银行有**：[HSBC](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/01-%E9%A6%99%E6%B8%AF-HSBC%E6%B1%87%E4%B8%B0%E9%93%B6%E8%A1%8C/01-%20HSBC%E9%A6%99%E6%B8%AF%E6%B1%87%E4%B8%B0%E9%93%B6%E8%A1%8C%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5%202026.md)、[恒生](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/04-%E9%A6%99%E6%B8%AF-%E6%81%92%E7%94%9F%E9%93%B6%E8%A1%8C/%E6%81%92%E7%94%9F%E9%93%B6%E8%A1%8C%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)、[中银香港](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/02-%E9%A6%99%E6%B8%AF-BOCHK%E4%B8%AD%E9%93%B6%E9%A6%99%E6%B8%AF/%E4%B8%AD%E9%93%B6%E9%A6%99%E6%B8%AF%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)、[渣打](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/03-%E9%A6%99%E6%B8%AF-%E6%B8%A3%E6%89%93%E9%93%B6%E8%A1%8C/%E6%B8%A3%E6%89%93%E9%93%B6%E8%A1%8C%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)、[众安银行](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/05-%E9%A6%99%E6%B8%AF-ZA%20%E4%BC%97%E5%AE%89%E9%93%B6%E8%A1%8C/%E4%BC%97%E5%AE%89%E9%93%B6%E8%A1%8C%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)。
    
- **新加坡：兼顾账户地区分散与华语使用体验**  
	- **优势**：新加坡是一个独立的主权国家，提供不同于香港的司法和金融监管制度，同时又能提供中文服务。
	- **劣势**：新加坡是 CRS 参与国。
	- **支持内地远程开户的新加坡银行有**：[星展（DBS）](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/11-%E6%96%B0%E5%8A%A0%E5%9D%A1-DBS%20%E6%98%9F%E5%B1%95%E9%93%B6%E8%A1%8C/%E6%98%9F%E5%B1%95%E9%93%B6%E8%A1%8C%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)、[华侨（OCBC）](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/12-%E6%96%B0%E5%8A%A0%E5%9D%A1-OCBC%E5%8D%8E%E4%BE%A8%E9%93%B6%E8%A1%8C/%E5%8D%8E%E4%BE%A8%E9%93%B6%E8%A1%8C%E9%A6%99%E6%B8%AF%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)、渣打。这几个银行的开户都有门槛，星展需要存入 100w，渣打需要存入 50w。
	
- **美国：无 CRS 交换** 
    - **优势**：美国不参与CRS ，这是大多数国人考虑美国银行账户的重要原因。
    - **劣势**：
	    - 维护成本：有最低存款要求，不满足会被收取账户管理费。
	    - 使用成本： 国内直接汇款到美国银行费用高、被拦截和审查的概率高。
	    - 使用便利：身处内地，处理账户验证、补卡或异常交易等需要考虑客服时差及远程办理限制。
	    - 隐形税务问题 ：虽然美国没有加入 CRS，但账户仍然受到美国当地税务法律约束。
    - **接受内地居民申请的美国银行**：华美银行、国泰银行。
- **其他地区**：[澳门蚂蚁银行](01-%20%E5%A2%83%E5%A4%96%E9%93%B6%E8%A1%8C%E8%B4%A6%E6%88%B7/31-%E6%BE%B3%E9%97%A8%E8%9A%82%E8%9A%81%E9%93%B6%E8%A1%8C/%E6%BE%B3%E9%97%A8%E8%9A%82%E8%9A%81%E9%93%B6%E8%A1%8C%E5%BC%80%E6%88%B7%E6%94%BB%E7%95%A5.md)

## 03- 了解跨境投资的合规风险

### 外汇风险

如果美股投资的资金需要从国内汇出去，这里就会面临第一个风险，就是外汇风险。

按照国家外汇管理局的规定，**个人跨境汇款出去的资金，只能用于境外消费和留学等指定目的，不能用于港险、港美股等投资。**

在实际操作中，大多数人都是以旅游、消费等名义购汇并将资金汇往香港，随后将这笔资金用于购买香港保险、港股或美股。按照外汇管理的规定，这个行为本身就是不合规的。

现实中为什么很少听到个人被外汇管理处罚呢？

因为外汇管理部门并不一定能够实时掌握资金汇出后的实际用途。

举个例子，你通过境内银行将一笔 5 万美元的资金汇到香港银行账户。这笔钱到了香港之后，究竟是用于日常消费，还是转入证券账户投资港美股，境内监管部门未必能够直接掌握。

境外银行通常也不会将客户的每笔交易用途主动报送给国家外汇管理局。当然，这并不意味着资金完全无法被追踪。银行的反洗钱监测、跨境监管协作等机制，仍然可能发现违规行为。尤其是涉及大额异常资金转移、地下钱庄、非法买卖外汇等情况，面临的监管和处罚风险就更高了。

这就好比交通法规明确规定不能闯红灯，但现实中仍然有不少人闯了红灯，却没有受到处罚。

**法律上的限制与现实中的执行，是两回事。没有受到处罚，不代表行为本身就是合法的。**

当然，我说这些，并不是鼓励大家违反外汇管理规定，而是希望大家对跨境投资的合规风险有一个清醒的认识。

**明知道存在风险，经过权衡后仍然选择承担，与完全不了解风险、盲目去做，是两种不同的情况。**

你可以选择承担风险，但至少应该先知道风险在哪里，以及可能付出的代价。

### 税务风险

按照我国《个人所得税法》的规定，中国税收居民不仅需要对境内所得缴税，对境外所得同样负有纳税义务。

其中，投资港美股取得的股票转让收益、股息红利等，通常适用 **20% 的个人所得税税率**。

这里就面临着一个现实问题：

**税务局要想征收你的境外投资所得税，首先得知道你在境外取得了这笔收入。**

过去，由于跨境金融信息不透明，税务机关获取个人境外投资收入信息的渠道相对有限，因此实际征管存在不少困难。

但随着 [CRS（共同申报准则）](03-%20%E8%B7%A8%E5%A2%83%E6%B3%95%E5%BE%8B%E6%B3%95%E8%A7%84%E5%9F%BA%E7%A1%80/CRS%20%E5%85%B1%E5%90%8C%E7%94%B3%E6%8A%A5%E5%9F%BA%E7%A1%80%E7%9F%A5%E8%AF%86.md)的实施，这种情况正在发生变化。

简单来说，CRS 就是一套国家和地区之间自动交换金融账户涉税信息的机制。

例如，中国内地税收居民在香港开立了银行或证券账户，符合 CRS 申报条件的情况下，香港金融机构会向香港税务局报送相关账户信息，再通过税务机关之间的信息交换机制，将这些信息提供给中国内地税务机关。


**这意味着，即使你的资金一直留在香港，没有汇回内地，内地税务机关也可以获知相关信息。**

事实上，从 2025 年开始，国内已有多地税务机关对未依法申报境外收入的个人开展提醒和查处。

所以，对于参与港美股投资的内地居民来说，税务风险已经不再只是纸面上的法律规定，而是现实中需要认真面对的问题。
